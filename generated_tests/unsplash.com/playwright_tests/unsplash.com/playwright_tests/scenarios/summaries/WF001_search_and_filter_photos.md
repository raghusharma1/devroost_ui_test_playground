## Navigation Hint

1. Navigate to https://unsplash.com
2. Type 'office' into the main search input field
3. Press Enter
4. Click the 'Orientation' filter dropdown and select 'Landscape'
5. Click the 'Color' filter dropdown and select 'Black and white'
6. Verify that the photo grid updates to show matching results.
